# 공통 기초 교재 집필 브리프 (2026-10-24)

`KSSB_BRIEF.md`의 JSON 형식·집필 규칙·검사를 따른다. 차이점만 적는다.

## 이 책들의 자리
- 서재의 "공통 기초" 영역. 진단 10문항(`data/diagnostic.json`)에서 8점 미만이면 KSSB보다 먼저 권한다. 그러니 **진단 문항이 묻는 개념을 모두 다뤄야** 한다(진단 파일을 먼저 읽는다).
- 독자: 기후·온실가스를 처음 보는 신입. 온실가스관리기사 1과목(기후변화의 이해)과 2과목 입문 수준.
- 기준서 하나를 따라 읽는 책이 아니므로, 블록 `no`는 문단 번호 대신 짧은 주제 표지("GWP", "Scope 2")를 쓴다. 각 블록에 `src`(공식 출처 URL 또는 문서명·쪽)를 반드시 단다.

## 두 권
### base-1 "온실가스와 Scope" (`data/books/base-1.json`, 회차 id b1-1~b1-5)
1. b1-1 온실가스란 무엇이고 왜 이산화탄소로 환산하나 (7대 온실가스, GWP, tCO2e, IPCC AR5·AR6 GWP 차이와 국내 적용)
2. b1-2 조직 경계: 무엇까지 우리 배출인가 (지분·재무통제·운영통제, 사업장)
3. b1-3 Scope 1·2·3 (직접·간접, 지역기반·시장기반, 15개 카테고리 개요)
4. b1-4 숫자를 만드는 법: 활동자료 × 배출계수, 기준연도와 재산정
5. b1-5 숫자를 믿게 하는 법: 데이터 품질, 검증·인증, 보고서에서 숫자 읽기(단위 함정: 천 톤 등)

### base-2 "기후 제도 전체 지도" (`data/books/base-2.json`, 회차 id b2-1~b2-4)
1. b2-1 국제: 기후변화협약, 파리협정, NDC, IPCC의 역할
2. b2-2 한국: 탄소중립기본법, 2030 NDC·2035 NDC, 배출권거래제, 목표관리제 (현재 수치는 반드시 공식 자료로 확인)
3. b2-3 공시 기준의 지도: TCFD → ISSB(IFRS S1·S2) → KSSB, EU ESRS, GRI, SASB, CDP 같은 평가 — 누가 누구를 위해 만들었나(투자자 vs 이해관계자, 재무 중요성 vs 이중 중요성)
4. b2-4 측정 표준의 지도: GHG 프로토콜, ISO 14064, IPCC 지침, 국내 보고·인증 지침, LCA(ISO 14040·14067) — 공시 기준과 측정 표준이 어떻게 맞물리나

## 출처
- 저장소의 기존 교재 `data/textbook/disclosure.json`, `regulation.json`, `lca.json`의 기초 장(id가 -0으로 끝나는 장)을 참고 자료로 쓴다(그대로 베끼지 말고 이 형식으로 다시 쓴다). 그 안의 사실도 확인하고 쓴다.
- 현재 수치·제도(국내 NDC, 배출권거래제 계획기간, 대상 업체 기준 등)는 WebSearch/WebFetch로 공식 자료(gir.go.kr, me.go.kr, law.go.kr, korea.kr, unfccc.int, ipcc.ch, ghgprotocol.org, ifrs.org)를 확인하고 src에 URL을 단다. 오늘은 2026-10-24다. 확인 못 하면 쓰지 않는다.
- 예시는 기아(`scratchpad/co/kia.txt`)·현대차(`scratchpad/dl/sr.txt`) 실제 숫자·문장만(scratchpad = /tmp/claude-0/-home-claude/f829a971-6193-524c-a7ea-a635bb21d323/scratchpad).
- 회차당 10~15분, 블록 3~5개.
