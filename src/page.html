How consultants work

신입이 첫 달에 받는 일, 그대로

과제 → 케이스 → 비교 → 판정 연습. 결과물은 전부 네가 쓴 문서이고, 그 문서가 포트폴리오가 된다. 점수는 보조다.

Career paths

지원하는 직무에 따라 순서가 바뀐다

기후공시 컨설턴트와 배출권거래제 담당자가 먼저 알아야 할 것은 다르다. 경로를 고르면 모듈 순서, 난이도, '다음에 풀 것' 추천이 그 경로 기준으로 바뀐다.

Learning record

작성자 김수현의 공개 기록

작성자가 직접 판정하고 쓴 기록이다. 문제와 모범 답안은 AI와 함께 만들었고, 판정·근거·개선안·처방은 작성자의 것이다.

Assignments

업무 과제

신입 컨설턴트가 첫 달에 실제로 받는 일 그대로다. 갭 분석표, 검산 메모, 검증 대응 점검표, 개정 비교표, 공시 문안. 과제 하나를 끝까지 채워 제출하면 리뷰를 받고, 고쳐서 다시 낸다. 결과물은 회사 문서 모양으로 나와 포트폴리오에 쌓인다.

Instructor

교육자 모드

같은 데이터 위에서 반 전체를 보는 화면이다. 4.0에서는 자리만 잡았고, 수강자 제출물 구조(수강자 · 과제 · 제출 버전 · 리뷰)가 그대로 DB 테이블이 된다.

Portfolio

진단·갭 분석·개선 포트폴리오

이 페이지에는 정답률이 없다. 실제 보고서를 기준에 대고 만든 갭 분석표와 진단 요약, 판정의 근거와 개선안, 두 회사를 비교해 쓴 처방만 있다. 글마다 원문 쪽이 붙어 있어 누구나 열어서 확인할 수 있다.

My path

내 경로

지원하는 직무를 고르면 단계별로 무엇을 어떤 순서로 풀지 정해 준다. 추천은 이 브라우저의 기록(정답률·최근 오답·복습 시기)으로 매번 다시 계산한다.

Case study

케이스 스터디

컨설턴트가 실제로 하는 순서다. 어떤 기준이 적용되는지 → 보고서 어디에 증빙이 있는지 → 충족했는지 → 근거를 글로 → 개선안을 글로. 마지막 두 단계는 네가 쓴 글이 답이고, 모범 답안은 비교용이다.

Side by side

기업 비교 · 현대차와 기아

같은 질문을 두 보고서에 던졌다. 판정이 다른 줄을 보고, 컨설턴트라면 어떤 처방을 쓸지 네 말로 적는다. 보고서는 정답지가 아니라 진단 대상이고, 기준서가 정답지다.

Modules

모듈과 영역

모듈은 기준서 단위다. 각 모듈의 기본 동작은 '해 보기'(판정·계산·상황 판단)이고, 입문 글은 막힐 때 읽는 참고다. 외우기용 문항은 뺐다. 각 모듈 아래 '기준 시점'은 문항이 전제하는 기준서 버전이다.

About

이 연습장을 만든 방법

컨설턴트가 처음 맡는 일은 기준서와 보고서를 나란히 놓고 '있는지, 충분한지'를 판단하는 일이다. 그 판단을 영역 전체에서 반복해 연습할 수 있게 만들었다.

01

영역 나누기

기후공시 컨설턴트의 업무를 공시 기준·측정과 검증·제도와 시장·실무와 평가의 4개 영역으로 나누고, 앞에 공시 체계 지도, 뒤에 기업 사례(현대차·기아)를 붙여 모듈을 짰다.

02

공식 자료로 대조

모듈마다 기준 제정기관, 감독기관, 법령의 공개 문서를 열어 조항과 숫자를 확인했다. 확인 못 한 것은 뺐거나 '확인 필요'로 표시했다. 문항마다 어떤 자료로 확인했는지가 꼬리표로 붙어 있다.

03

숫자는 코드로 검산

계산 문항의 답과 풀이 단계는 Python으로 다시 계산했다. 보고서 숫자는 쪽 번호를 함께 적어 원문을 바로 열 수 있게 했다.

04

AI 교차 검토

문제를 만들지 않은 별도의 AI 검토 세션 여섯 갈래가 인용문·숫자·조항을 다시 대조했고, 지적 사항을 반영했다. 사람 전문가의 검토는 아직 받지 않았다.

AI(Claude)가 한 일

  • 영역 설계, 원문·기준서 대조, 문항·입문 글·회사 팩 작성
  • 계산 검산과 AI 교차 검토
  • 웹앱 설계와 구현

김수현이 한 일

  • 채용공고 업무 범위에 맞춘 기준 선정, 전 영역 확장과 취업 경로별 학습 설계 기획
  • "보고서를 역으로 읽는 게 정답지 베끼기 아니냐"는 문제 제기 → 케이스 스터디와 처방 쓰기로 설계 변경
  • 문제 풀이, 판단 근거·개선안·처방 작성(내 기록), 기준서 검색용 RAG 직접 구현(진행 중)

한계

  • 정답은 공개 자료를 대조한 해석이며, '일부'와 '없음'의 경계는 전문가마다 다를 수 있다.
  • KSSB·ESRS·GHG 프로토콜은 개정이 진행 중이라 모듈의 '기준 시점'과 문항의 기준 연도를 확인해야 한다.
  • 평가기관의 세부 채점 기준과 일부 유료 기준서 원문은 확인하지 못했다. 아래 신뢰도 표에 문항 수로 적었다.
