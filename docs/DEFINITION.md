# 리빌딩 정의서 v1.2

작성 2026-10-23 · 검토자 김수현 · **이 문서가 확정되기 전에는 코드를 만지지 않는다.**

## 0. 한 문장

기후공시·온실가스·LCA·법령의 **기준서를 한 권씩, 문단 순서대로 함께 읽는** 교육 사이트. 읽은 직후 한 줄로 써 보며 확인하고, 다 읽으면 실제 보고서로 선택 실습을 한다.

## 1. 목표

- **1차 (지금)**: 신입 컨설턴트(=나)가 실무에 쓰는 기준서를 처음부터 끝까지 한 번씩 읽어 본 상태가 된다. 어느 문단에 무엇이 있는지 감이 생긴다.
- **2차 (나중)**: 내가 신입·외부 교육을 할 때 "기준서 함께 읽기" 교재로 쓴다.
- **안 하는 것**: 게임화(클래스·전직·XP·보드), 암기 문제, 문제 위주 학습, S·G 영역, 산정 계산기, 재무영향 시뮬레이터, 게시판, 로그인·DB, **교육자 모드**(당분간 제외).

## 2. 대상자

- **주 대상**: 기후·환경 전공 또는 온실가스관리기사 수준의 취업 준비생·신입. Scope가 뭔지 모를 수 있다.
- **부 대상**: 사내 교육을 받는 비전공 실무자.
- **전제**: 하루 15~20분, 주 3~5회. 한 회차에 기준서 1~3문단 분량.

## 3. 핵심 원칙

| # | 원칙 |
|---|---|
| P1 | **읽기가 본체, 확인은 손님.** 시간 배분 읽기 8 : 확인 2. |
| P2 | **과목 = 기준서 한 권.** 회차는 그 기준서의 목차(문단) 순서를 따른다. |
| P3 | **확인은 "내 말로 한 줄 쓰기"가 기본.** 키워드 채점(API 없이 동작). 객관식은 헷갈리는 지점에만 쪽당 1개 이하. |
| P4 | **문제는 선택.** 기존 504문항은 과목 끝 "더 풀어 보기"로 숨긴다. |
| P5 | **일정 분량마다 정리.** 과목 끝과 주 1회 "배운 것 정리" 자동 생성. |
| P6 | **출처를 붙인다.** 모든 설명은 기준서 문단 번호(또는 공식 자료)에 묶인다. 원문을 못 연 것은 "(2차 자료 기준)" 표시, 확인 못 하면 쓰지 않는다. |
| P7 | 학습 > 재미. 진행 표시는 과목 진행 그림(회차 점 n/m)만. |
| P8 | 쉬운 말 우선, 공식 용어·영문은 처음 한 번 병기. 예: 기능단위(functional unit). |

## 4. 구조

```
영역 (4) → 과목 = 기준서 (약 22) → 회차 = 1~3문단 (15~20분) → 활동
```

**회차 템플릿**

| 순서 | 활동 | 분량 | 통과 조건 |
|---|---|---|---|
| 1 | **읽기** — 문단 요지 해설, 그림·표, 실제 예 상자 | 교재 1~2쪽 (10~14분) | 끝까지 스크롤 |
| 2 | **한 줄 쓰기** — "방금 읽은 문단이 요구하는 것을 네 말로" | 30~150자 (3~5분) | 키워드 70% 이상, 2회까지 재시도 후 모범 답안 공개 |
| 3 | **헷갈림 점검** (있을 때만) — 객관식 1문항 | 1분 | 없음 (틀리면 복습 큐) |

- **회차 완료** = 읽기 끝 + 한 줄 쓰기 통과(또는 재시도 2회 후 모범 답안 확인).
- **과목 이수** = 모든 회차 완료. 재수강 가능(기록 유지).
- **과목 끝**: ① 배운 것 정리 ② 더 풀어 보기(기존 문항, 선택) ③ 선택 실습.

## 6. 첫 과목: KSSB 제1·2호

**왜 KSSB부터**: 한국 의무공시의 실제 기준이고, IFRS S1·S2를 바탕으로 해서 KSSB를 읽으면 IFRS가 저절로 따라온다. 공시 지원자에게 가장 먼저 필요하다.

**회차 구성 초안** (기준서 목차 순서, 최종 회차 수는 원문 확인 후 조정)

| 회차 | 범위 | 핵심 |
|---|---|---|
| 0 | 들어가며 | KSSB는 누구이고, 금융위 로드맵(대상·시기·Scope 3 유예·인증·면책)은 어떤가 |
| 1 | 제1호 목적·적용범위 | 누가, 무엇을, 왜 공시하나 |
| 2 | 제1호 개념적 기초 | 중요성, 보고기업, 연계된 정보 |
| 3 | 제1호 핵심 요소 | 거버넌스·전략·위험관리·지표 및 목표 네 기둥 |
| 4 | 제1호 일반 요구사항 | 정보의 위치, 보고 시점, 비교 정보, 준수 선언 |
| 5 | 제1호 판단·불확실성·오류 | 추정, 측정 불확실성, 오류 수정 |
| 6 | 제1호 경과 규정 | 첫해 경감 |
| 7 | 제2호 목적·범위 | 기후 관련 위험과 기회 |
| 8 | 제2호 거버넌스 | 이사회·경영진의 역할 |
| 9 | 제2호 전략 ① | 위험·기회 식별, 사업모형·가치사슬 영향 |
| 10 | 제2호 전략 ② | 재무적 영향, 기후 회복력과 시나리오 분석 |
| 11 | 제2호 위험관리 | 식별·평가·통합 절차 |
| 12 | 제2호 지표 ① | 온실가스 Scope 1·2·3, 측정 방법별 구분(KSSB 고유) |
| 13 | 제2호 지표 ② | 산업 교차 지표, 내부탄소가격(선택공시), 보상 |
| 14 | 제2호 목표 | 목표의 요소, 성과 공시 |
| 15 | IFRS와 다른 점 정리 | 선택공시 항목, 추가 요구, 유예 |
| 정리 | 배운 것 정리 | 핵심 문장·내가 쓴 한 줄들·틀린 점검 |
| 실습 | 선택 | 기아 보고서로 KSSB 의무공시 준비 점검표(기존 과제 6줄) |

**대략 16회차 · 4~5시간 · 교재 약 25~35쪽**

**⚠ 선결 조건**: KSSB 기준서 원문(kssb.or.kr)은 지난 작업에서 접속이 막혀 **2차 자료로만** 썼다. 첫 과목이 KSSB이면 원문 없이는 P6(출처 원칙)을 지킬 수 없다. → **김수현이 KSSB 제1호·제2호 확정본 PDF를 첨부**하면 그것을 기준으로 문단 번호를 맞춰 쓴다. 금융위 2026-07-08 최종안은 fsc.go.kr에서 확인 가능.

## 7. 한 줄 쓰기 — 키워드 채점 규격

```json
{
  "id": "kssb-2-12-w1",
  "prompt": "제2호가 온실가스 배출량을 '측정 방법별로 구분'하라고 하는 이유를 한 문장으로.",
  "must":   [["배출권거래제","K-ETS","국내 지침"], ["GHG 프로토콜","국제"], ["구분","나누어","따로"]],
  "bonus":  [["비교","이용자"]],
  "wrong":  ["Scope 3 제외"],
  "min": 30, "max": 200,
  "model": "한국 회사는 배출권거래제 지침과 GHG 프로토콜을 함께 쓰는 경우가 많아, 어느 방법으로 계산한 숫자인지 이용자가 구분할 수 있게 하려는 것이다.",
  "src": "KSSB 제2호 문단 __ (원문 확인 후 기입)"
}
```

- `must`: 묶음마다 동의어 중 하나만 있으면 그 묶음 충족. 점수 = 충족 묶음 / 전체 묶음.
- `bonus`: 있으면 +10%(최대 100%). `wrong`: 있으면 −30%와 이유 표시.
- 70% 이상 통과. 2회 미달 시 모범 답안 공개 + 복습 큐.
- 키워드는 **교재를 쓰는 사람이 같이 쓴다.** 아티팩트 안에서는 통과 후 AI가 "더 좋은 문장" 코멘트(선택).

## 8. 정리·복습

- **과목 끝 정리 카드**: 핵심 문장 5개(교재에서 지정) + 내가 쓴 한 줄 중 3개 + 틀린 점검 + "다음 과목" 안내.
- **주간 정리**: 매주 월요일 첫 접속 시 지난주 읽은 회차 요약.
- **복습 큐**: 미달 한 줄 쓰기·틀린 점검 → 1·3·7·14일. 복습은 "그 문단 다시 읽기 + 한 줄 다시 쓰기".

## 9. 진단

- 10문항: 기초 4 · 공시 2 · 관리 2 · LCA 1 · 법령 1.
- 8점 이상 → 기초 과목 "건너뛰어도 됨" 표시. 미만 → "먼저 권장".
- 결과는 권장 표시만 바꾼다(잠금 없음). 언제든 재진단.

## 10. 화면 (4개)

| 화면 | 내용 |
|---|---|
| **홈** | 오늘의 회차 1개(이어 읽기) · 내 과목(진행 그림) · 전체 과목 목록(영역별, 권장 경로 필터) · 복습 n개 |
| **읽기** | 회차 한 페이지: 읽기 → 한 줄 쓰기 → 점검. 상단에 과목 진행 점, 기준서 문단 번호 |
| **포트폴리오** | 내가 쓴 한 줄·실습 산출물, 원문 쪽 링크. 삭제·되돌리기·인쇄 |
| **참고** | 도서관(과목별 교재 전체), 용어집(제목 우선 검색), 기준 지도, 만든 방법 |

메뉴: 홈 · 포트폴리오 · 참고 · [다크/라이트]. **모바일 우선**(15~20분 회차는 폰에서 읽는 일이 많다).

삭제: 진로 선택, 보드, 레벨·점수, 교육자 모드, 케이스·비교의 독립 메뉴(→ 선택 실습으로).

## 12. 성공 기준 (v1)

- KSSB 과목을 내가 끝까지 읽고, 한 줄 쓰기 통과율과 회차 실제 소요 시간(목표 15~20분)을 기록한다.
- 실무자 1명이 KSSB 교재 5쪽 + 한 줄 쓰기 키워드 10개를 검수한다.
- 선생님 검토 통과.

## 13. 작업 순서
